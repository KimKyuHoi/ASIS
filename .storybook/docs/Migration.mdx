# 도메인 마이그레이션 가이드

도메인 CSS 는 아직 각자 `:root` 를 정의하고 날값을 쓴다. 옮기는 순서는 다음과 같다.

1. 도메인 `styles.css` 맨 위에 `@import '../../design-system/asset/base.css';` 를 넣는다. 도메인의 `:root { … }` 블록과 `* { box-sizing … }` 리셋은 지운다.
2. 아래 변수 표대로 이름을 바꾼다.
3. 반복되는 버튼·셀렉트·토글 마크업은 React 컴포넌트로 바꾼다.
4. 남은 날값은 `token-audit` 으로 찾아 토큰으로 바꾼다.
5. 화면을 라이트·다크·대비 증가에서 모두 확인한다.

레거시 클래스는 이제 컴포넌트 토큰을 참조한다. 그래서 gif-studio·pin·step-guide 는 고치지 않아도 오렌지 강조색과 AA 보정이 적용된다.
화면에서 달라지는 점은 두 가지다. 기본 버튼이 파랑에서 브랜드 오렌지(#FF6F0F, 흰 글자 — AA 의도적 미적용)로 바뀌고, HUD 정지 버튼이 조금 어두운 빨강이 된다(흰 글자 4.6:1).
모든 도메인이 컴포넌트로 옮겨 가면 base.css 의 레거시 블록을 지운다.

## 권장 순서 (작은 것 → 큰 것, 겹치는 것 먼저)

1. **pin, step-guide, gif-studio** — 이미 base.css 를 쓴다. 남은 날값만 감사로 정리한다.
2. **countdown, patch-history, onboarding** — 작고 독립적이다. 첫 실행 화면이라 라이트·다크 효과가 바로 보인다.
3. **settings** — `Group`/`Row`/`Toggle`/`Select`/`KeyCap` 을 가장 많이 쓰는 곳이다. 대문자 섹션 제목도 여기서 없앤다.
4. **history** — `EmptyState`, `Badge`, `Toolbar`.
5. **recorder + video-recorder** — 거의 중복이라 HUD 컴포넌트로 하나로 합친다. 항상 다크.
6. **scroll-capture** — HUD 와 캡처 프레임.
7. **selection** — 캡처 오버레이. `CaptureFrame` 과 `--frame-*` 를 쓰고, 성능에 민감하니 마지막에 한다.
8. **editor** — 가장 크다. Konva 캔버스 안의 주석 색(사용자가 고르는 색)은 토큰 대상이 아니다. 툴바·패널만 옮긴다.
