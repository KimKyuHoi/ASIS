# ASIS 디자인 시스템

캡처한 화면을 설명하는 도구답게, **UI는 조용히 물러나고 캡처한 화면이 주인공**이 되게 한다.

- **macOS 구조, 따뜻한 톤** — 크기·반경·그림자·시스템 색은 macOS 를 따른다. 바탕과 회색에는 따뜻한 기운을 넣어 오래 봐도 눈이 편하게 한다.
- **ASIS 오렌지** — 메인 색은 밝은 주황(`#ff6f0f`) 하나다. 선택·켜짐·기본 동작에만 쓰고, 그 위 글자는 흰색이다(당근처럼 색을 우선, AA 의도적 미적용). 넓은 면에는 복숭아빛 틴트를 쓴다.
- **캡처 프레임** — 개성은 한 곳에만 쓴다. 얇은 선과 네 모서리의 굵은 브래킷으로 그리고, 녹화 중에는 빨강으로 바뀐다.
- **라이트 / 다크 / 대비 증가** — 모든 토큰이 세 가지 외형을 다 가진다. 캡처 오버레이와 HUD는 어떤 앱 위에 떠도 읽히도록 항상 다크다.
