## 새 기능

- **익명 사용 통계** — 설치 수와 사용자 수를 세기 위해 하루 한 번 무작위 설치 ID·앱 버전·macOS 버전만 보냅니다. 이름·파일·화면 내용은 보내지 않으며, 설정의 "익명 사용 통계 보내기"로 언제든 끌 수 있습니다.

## 개선

- GIF 스튜디오 내보내기 설정을 단순하게 정리했습니다. 내보낸 GIF는 항상 반복 재생되고, 크기는 픽셀로 입력하거나 크기 프리셋으로 고릅니다.
- GIF 스튜디오의 "비율 유지"가 지금 크기가 원본 비율인지를 그대로 보여 줍니다. 너비·높이를 고쳐 비율이 깨지면 저절로 꺼지고, 다시 체크하면 원본 비율로 돌아갑니다.

## 고친 점

- GIF 스튜디오에서 크기 선택 상자가 열리자마자 닫히던 문제를 고쳤습니다. 너비·높이 입력칸을 누른 뒤 바로 입력이 안 되던 문제도 함께 고쳤습니다.
- 0.8.0 첫 배포본에서 설치 직후 "Cannot find module 'ms'" 오류로 앱이 실행되지 않던 문제는 0.8.0 재배포본부터 고쳐졌습니다. 이 오류를 겪으셨다면 자동 업데이트가 동작하지 않으니 DMG를 다시 받아 설치해 주세요.

## 제거

- GIF 스튜디오의 바운스(역재생 이어 붙이기), 재생 횟수 설정, 퍼센트 단위 입력을 뺐습니다.
