## New

- **Anonymous usage statistics** — To count installs and users, ASIS sends only a random install ID, the app version, and the macOS version once a day. No names, files, or screen content are sent, and you can turn it off anytime with "Send anonymous usage statistics" in Settings.

## Improved

- GIF Studio's export settings are simpler. Exported GIFs always loop, and size is set in pixels or with a size preset.
- "Keep aspect ratio" in GIF Studio now shows whether the current size matches the original ratio. Editing the width or height so the ratio breaks turns it off, and checking it again restores the original ratio.

## Fixed

- Fixed size dropdowns in GIF Studio closing as soon as they opened. Typing right after clicking the width or height field now works too.
- The first 0.8.0 build failed to launch with "Cannot find module 'ms'"; this was fixed in the re-released 0.8.0. If you hit this error, automatic updates can't run, so please download and reinstall the DMG.

## Removed

- Removed GIF Studio's bounce (reverse playback), play count setting, and percent size input.
